📥 导入 Excel / CSV

直接选择你电脑里的 .xlsx / .xls / .csv 文件即可导入（Excel 无需先转 CSV）；表头支持「公司名称 / 职位名称 / 工作地点 / 薪资范围 / 招聘渠道 / 投递日期 / 当前状态 / 下次跟进日期 / 面试时间 / 简历版本 / 标签 / 职位链接 / 测评链接 / 测评状态 / 备注」等中文列。必填仅「公司名称 + 职位名称」，其余为空也行（测评状态缺省按「未测评」处理）。支持合并（按公司+职位去重）或覆盖两种模式，导入后渠道、状态会与系统选项自动匹配。
