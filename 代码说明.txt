========================================================
求职投递管理网页应用（job-tracker.html）代码与使用说明
========================================================

一、这是什么
--------------------------------------------------------
这是一个"单文件"个人求职投递管理网页应用，用于记录和跟踪向不同
公司投递简历的进度、管理简历版本、记录面试与沟通、设置跟进提醒，
以及在应用内直接浏览常用的招聘 / 信息站点。
- 技术栈：原生 HTML + CSS + JavaScript，仅按需引入 SheetJS（xlsx）
  用于解析 Excel 文件
- 数据存储：浏览器 localStorage（本地保存，无需联网、无需服务器）
- 整个应用就是一个 job-tracker.html 文件，所有样式和脚本均内联

二、如何运行
--------------------------------------------------------
1. 直接用浏览器（推荐 Chrome / Edge）双击打开 job-tracker.html 即可。
2. 数据只保存在"当前浏览器"的本地：换浏览器、换电脑、或清除浏览器
   数据都会导致记录丢失，请养成在【数据管理】页定期"导出数据"备份的习惯。
3. 导出的 JSON 文件可随时通过【数据管理】页重新导入（支持合并/覆盖）。
4. 可选：本目录的 monitor-proxy.py 是 0 依赖的本地代理，仅当目标网站
   禁止被内嵌浏览时才需要运行（详见第九节）。

三、功能模块（顶部 7 个 Tab）
--------------------------------------------------------

1. 投递列表（默认页）
   - 卡片形式展示全部投递记录，默认按投递日期倒序
   - 筛选：状态 / 渠道 / 投递日期范围 / 标签关键词；搜索：公司或职位名
   - 排序：按投递日期 / 公司名称 / 状态，可切换升序降序
   - 操作：编辑、删除（二次确认）、点击状态徽章快速切换状态
   - 星标 ⭐：重要公司可置顶，会以渐变高亮卡片显示在列表最前
   - 复制记录：表单内一键复制一条已有记录，仅修改日期与状态即可投递同岗
   - 批量操作：勾选多条 → 批量删除 / 批量改状态 / 批量改标签 / CSV 导出
   - 招聘渠道：内置 20 项（BOSS直聘、智联、前程无忧、猎聘、拉勾、实习
     僧、牛客网、脉脉、领英、大街网、海投网、应届生求职网、校招/双选
     会、58 同城、赶集网、猎头推荐、内部推荐、公司官网、微信公众号、
     其他），可通过表单内的"＋ 新增渠道"永久添加自定义项
   - 返回顶部：列表较长时向下滚动，右下角自动出现「↑ 返回顶部」浮动按钮，
     点一下即可一键回到页面顶部，方便长列表快速定位

2. 统计看板
   - 总投递数、本周/本月新增、投递成功率（Offer 数÷总数）、面试转化率
   - 各状态数量彩色条形图（纯 CSS 实现）
   - 最近 14 天新增投递趋势折线图、渠道分布饼图（原生 Canvas 绘制）
   - 出现最多的前 10 个标签

3. 简历版本库
   - 管理多份简历（如"通用版-前端"、"针对大厂版"），支持增删改
   - 附件限 PDF/DOC/DOCX，≤2MB 保存文件内容，>2MB 仅保存文件名
   - 保存了内容的版本可直接下载；投递表单的"简历版本"下拉选项来源于此

4. 跟进提醒
   - 列出所有设置了"下次跟进日期"的记录，按日期从近到远排序
   - 显示"今天 / 明天 / N 天后 / 已过期 N 天"：过期红色、今天橙色、未来绿色
   - 单条"完成跟进"（可同时补一条联系记录），或一键"全部标记已跟进"
   - 到期/过期的跟进事项会在页面内弹出提醒卡片，无需任何权限设置
   - "🔔 提醒汇总"按钮可一屏看全当前三类待办；"⚡ 立即提醒"可随时手动触发
   - 每条待办卡片下方直接展示「🔗 职位链接」「📝 测评链接」「✍️ 笔试链接」，链接缺失时给出
     「暂无职位链接 / 暂无测评链接 / 暂无笔试链接」提示，绝不错漏；右下角同样有「↑ 返回顶部」按钮
   - 设置"下次跟进日期"时可一并填写**跟进原因**（表单提供常用选项：等待笔试结果 / 等待面试通知 /
     等待 HR 回复 / 等待 Offer / 追问投递进度 / 确认面试安排 / 礼貌性跟进 / 补充材料 / 催推进度 /
     电话未接通需再约，也可手动输入自定义）；"完成跟进"弹窗里也能顺带安排下次跟进日期与原因
   - **笔试与综合测评分开管理**：笔试有独立的「笔试链接」与笔试状态（未笔试 / 已笔试），在「投递列表」表单
     与「详情」页分别填写/切换，不会和综合测评混在一起
   - **笔试提醒（仅对需要笔试的公司）**：每条投递可标记「是否需要笔试」（需要笔试 / 仅测评无需笔试 / 待确认）。
     提醒系统只对标记为「需要笔试」的公司弹出笔试提醒——已收链接的提示"待完成笔试"、未收链接的提示"留意邮箱待收笔试"；
     明确「仅测评（无需笔试）」的公司完全不会被笔试提醒打扰；"待确认"且无链接的公司也不打扰（避免误判）。
     页面顶部快捷筛选新增「待笔试」可一键筛出所有需要笔试且未完成的投递
   - **记录卡片上直接显示笔试状态**：「投递列表」与「跟进提醒」的每条记录标题旁都会显示笔试徽章
     （✍️ 待笔试 / ✅ 已笔试 / ❓ 笔试待确认），点一下即可切换状态；标记为「仅测评（无需笔试）」的
     记录不显示该徽章，列表保持清爽

5. 面试日历
   - 月历视图（周一为一周开始），可切换上/下月、回到今天
   - 有面试的日期显示公司+职位条目，点击查看详情并可跳转编辑该记录

6. 数据管理
   - 导出：全部数据导出为 JSON（文件名含日期，如 job_applications_2026-08-28.json）
   - 导入：合并模式（按 公司+职位+投递日期 去重，重复可选跳过或覆盖）
           覆盖模式（清空现有数据后导入）
   - Excel / CSV 导入：支持 .xlsx 与 .csv 直接导入；提供"下载模板"
     按钮获取标准模板（必填项仅"公司"和"职位"，其余留空也行）
   - 导出 CSV：可单独导出当前筛选结果，或"导出勾选"的批量结果
   - 清空全部数据（二次确认）；实时显示存储占用及 5MB 上限预警

7. 网站导航
   - 左侧：自定义网站列表（最多添加任意多个）
     · 每张卡片显示站点头像（取 favicon）+ 域名；悬停出现 ✕ 删除
     · 点任意卡片即在右侧内嵌浏览该网站
   - 右侧：纯净的内嵌浏览器
     · 顶栏：⟳ 刷新 / 地址栏（显示当前 URL）/ ↗ 新窗口
     · 内容区：以 iframe 内嵌显示目标网站的实时内容
   - 左栏底部"⚙️ 高级设置 / 代理"（默认折叠，不影响浏览区）
     · 代理开关：勾选后改用代理加载，可解决部分站点禁止被内嵌的问题
     · 代理模板：自定义代理地址（含 {url} 占位符）

四、视觉与主题
--------------------------------------------------------
- 浅色 / 深色主题一键切换（顶栏 ☀️ / 🌙），选择会永久记住
- 主色升级为「蓝 → 靛渐变」体系：品牌 / 激活 Tab / 主按钮均为渐变
- 卡片加描边，悬停微浮；统计卡顶部渐变色条 + 渐变数字
- 页面背景带极淡的径向光晕；弹窗标题下方有渐变线
- 圆角加大；表单输入在深色模式下不再白底

五、招聘渠道自定义
--------------------------------------------------------
- 在【投递列表】的"新增 / 编辑"弹窗中，渠道下拉框末尾有"＋ 新增渠道"
- 输入名称后回车，会立刻加入本地下拉列表，并永久写入 localStorage
  （即使关闭浏览器、刷新页面也保留）
- 自定义渠道同样可用于筛选、统计、导出

六、页面内提醒
--------------------------------------------------------
提醒完全在页面内完成，不依赖浏览器通知权限，也不需要额外启动脚本：

1. 打开页面后，若存在待办（跟进到期 / 网申临近或过期 / 有待完成的综合测评 / 有待完成的笔试），
   会在右上角自动滑入提醒卡片（每次会话只弹一次，不会反复打扰）
2. 点【跟进提醒】页的"⚡ 立即提醒"，可随时重新弹出当前所有待办
3. 点"🔔 提醒汇总"，可在一个弹窗里看全四类待办（笔试提醒只针对标记为"需要笔试"的公司）
4. 【跟进提醒】标签上的数字角标 = 待处理提醒条数
5. 卡片可手动关闭，10 秒后也会自动消失；回收站里的记录不参与提醒

七、本地代理（monitor-proxy.py，可选）
--------------------------------------------------------
- 默认情况下【网站导航】Tab 直接以 iframe 内嵌显示目标网站
- 部分站点会通过 X-Frame-Options / CSP 拒绝被内嵌，iframe 显示空白
- 此时可运行 monitor-proxy.py（在 8787 端口）作为本地代理：
    python monitor-proxy.py
- 然后在【网站导航 → ⚙️ 高级设置 / 代理】里：
    1. 勾选"代理"开关
    2. 代理模板填：http://localhost:8787/?url={url}
    3. 保存即可

八、数据备份建议
--------------------------------------------------------
- localStorage 在浏览器隐私模式、跨浏览器、跨设备不会同步
- 推荐做法：每隔 1～2 周到【数据管理】导出 JSON 备份到网盘或邮箱
- 同时建议把 job-tracker.html 与 monitor-proxy.py 一并存档

九、文件清单
--------------------------------------------------------
- job-tracker.html：主应用（唯一需要打开的文件）
- monitor-proxy.py：可选的本地 CORS 代理，零依赖（仅用 Python 标准库）
- 代码说明.txt：本说明文档

十、常见问题
--------------------------------------------------------
Q：打开页面后一片黑？
A：可能在深色模式下。点顶栏右侧的 ☀️ 切回浅色；切换会记住。

Q：数据怎么迁移到新电脑？
A：在【数据管理】导出 JSON，到新电脑的同浏览器打开后导入即可。

Q：为什么某个网站在【网站导航】里显示空白？
A：该站点禁止被内嵌。按第七节运行本地代理并启用代理模板。

Q：导入 Excel 报"格式不对"？
A：先点"下载模板"按模板整理后再导入；必填项只有"公司"和"职位"。
