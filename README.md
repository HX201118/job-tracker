# 求职投递管理 (Job Tracker)

一个**纯前端、零依赖、单文件**的求职投递管理工具。所有数据保存在浏览器本地（`localStorage`），无需服务器、无需注册、无需联网即可使用。

> 适合正在找工作的同学集中管理投递记录、跟进状态与面试安排，不再用 Excel 手动维护。

---

## ✨ 功能特性

- 📋 **投递列表**：添加 / 编辑 / 删除记录，支持搜索、按状态 / 渠道 / 测评 / 标签 / 日期区间筛选与排序，并提供批量管理。
- 📊 **统计看板**：投递趋势、状态分布等数据可视化，快速了解求职进度。
- 📄 **简历版本库**：管理针对不同岗位打磨的多份简历版本。
- ⏰ **跟进提醒**：记录面试、后续动作等跟进事项，支持系统级桌面通知。
- 🗓️ **面试日历**：按日期直观查看面试安排。
- 💾 **数据管理**：CSV 导入 / 导出、本地备份与恢复，方便换设备或长期保存。
- 🌐 **网站导航**：内置常用招聘网站导航，可自定义，并支持可选的本地代理用于跨域内嵌浏览。
- 📝 **综合测评提醒**：投递后默认「未测评」，可一键切换为「已测评」并填写测评链接，支持按测评状态筛选与系统通知，再也不漏掉企业的测评。
- 🌙 **深色 / 浅色主题**：一键切换，自动记忆偏好。

---

## 🚀 快速开始

1. 克隆或下载本仓库；
2. 直接用浏览器（推荐 Chrome / Edge）打开 `job-tracker.html` 即可使用；
3. 首次使用建议前往「💾 数据管理」页导出一份 CSV 作为备份。

无需安装任何依赖、无需构建步骤、无需联网（「网站导航」页的内嵌浏览需要联网）。

> ⚠️ 直接双击打开属于 `file://` 方式，浏览器（Chrome / Edge）会**禁用系统通知**。若需要真正的桌面通知，请用下面的「系统通知模式」启动。

## 💾 数据存储与备份

- 数据保存在当前浏览器的 `localStorage`，**仅存在于你正在使用的这台浏览器**，不上传任何服务器。
- 换设备 / 换浏览器**不会自动同步**，请使用「💾 数据管理 → 导出 CSV / 备份」定期保存。
- 清空浏览器缓存或数据会丢失记录，重要数据请务必及时备份。

## 🔔 桌面通知（系统级）

系统通知要求页面运行在 `http://` 协议下，浏览器才允许授权：

**方式一：系统通知模式（推荐）**

双击项目目录里的 **`启动-系统通知版.bat`**（需已安装 Python 3），它会：
1. 在本机 8765 端口启动一个只监听 `127.0.0.1` 的静态服务；
2. 自动用浏览器打开 `http://127.0.0.1:8765/job-tracker.html`；
3. 在页面「⏰ 跟进提醒」中点击 **🔔 开启桌面提醒** 并允许授权，即可弹出系统通知。

关闭那个黑窗口（或 Ctrl+C）即停止服务，数据全部保存在浏览器本地，不受影响。

**方式二：任意本地服务器**

用 VS Code 的 Live Server、`npx serve`、`python -m http.server` 等任意方式以 `http://localhost` 打开本页也可以。

**没有系统通知时也不会漏**

点「⚡ 立即提醒」会在**页面右上角弹出提醒卡片**（滑入动画、可手动关闭、自动消失），这是与权限无关的兜底；若未授权，还会同时打开「提醒中心」弹窗，给出开启系统通知的入口。

**三类提醒**：求职跟进（到期/过期）、网申截止（≤3 天 / 已过期）、综合测评（已收到链接待完成 / 未收到链接留意邮箱）。

> 想快速验证效果：在「⏰ 跟进提醒」页点 **🧪 生成演示数据**，会插入 3 条覆盖上述场景的示例记录，并立即触发一次提醒；测试完可到「🗑️ 回收站」一键清理。
