# 求职投递管理（Job Tracker）

一个**纯前端、零依赖、单文件**的求职投递管理工具。所有数据保存在浏览器本地（`localStorage`），不上传服务器、不需要注册、断网也能用（只有导入 Excel 与内嵌浏览网站需要联网）。

> 适合正在找工作的同学集中管理投递记录、笔试 / 测评、跟进状态与面试安排，不再用 Excel 手工维护。

## 🚀 快速开始

1. 下载或克隆本仓库；
2. 用浏览器（推荐 Chrome / Edge）**双击打开 `job-tracker.html`** 即可使用；
3. 🚀 **推荐先用 Excel 快速初始化**（比一条条手敲快得多）：
   - 如果你**已经有一份自己的投递台账 Excel / CSV**：直接到「💾 数据管理 → 📥 导入 Excel / CSV」选中它即可。列名支持常见中文表头自动匹配（公司名称 / 职位名称 / 工作地点 / 薪资范围 / 招聘渠道 / 投递日期 / 当前状态 / 下次跟进日期 / 面试时间 / 简历版本 / 标签 / 职位链接 / 测评链接 / 测评状态 / 备注……），**必填只有「公司名称 + 职位名称」**，其余留空也行；
   - 如果还没有：点「⬇ 下载导入模板」拿一份标准模板，按列填好再导入；
   - 导入时可自由选择**合并**（按 公司+职位+投递日期 去重）或**覆盖**，导入后渠道、状态会自动与系统选项匹配。
4. 之后零散的新增，用右上角「＋ 添加记录」补录即可（也可点卡片右上角「复制」快速复用一条相近记录）；
5. 养成习惯：每隔一两周到「💾 数据管理」导出一份 JSON 备份。

> 💡 用 Excel 初始化的好处：几十上百条投递一次性进来，测评 / 笔试状态、渠道、标签都能批量带过来，进来后就可以直接用快捷筛选和提醒了。导入 Excel 时需要联网加载一次解析库，其余功能完全离线可用。

无需安装依赖、无需构建、无需服务器。

## 🗺️ 界面总览

采用**经典的左右两栏布局**：左侧是固定窄导航栏（8 个标签页 + 深色 / 浅色主题切换），右侧是主内容区，**宽度占满全屏**；筛选、搜索、快捷筛选等控件固定在内容区顶部。

| 标签页（左侧导航） | 作用 |
| --- | --- |
| 📋 投递列表 | 核心模块：录入、筛选、排序、批量管理所有投递记录 |
| 📊 统计看板 | 数量、转化率、趋势、渠道、城市、薪资、标签等可视化统计 |
| 📄 简历版本库 | 维护不同岗位的简历版本与附件 |
| ⏰ 跟进提醒 | 跟进待办清单 + 待测评清单 + 提醒中心（角标显示待办数） |
| 🗓️ 面试日历 | 月历视图查看面试安排 |
| 💾 数据管理 | JSON / Excel / CSV 导入导出、存储占用、清空数据 |
| 🗑️ 回收站 | 删除的记录暂存在此，可恢复或永久删除（角标显示条数） |
| 🌐 网站导航 | 内置常用招聘站点，右侧内嵌浏览 |

右上角 ☀️ / 🌙 按钮切换深色 / 浅色主题，选择会被记住（窄窗口下侧边栏会自动恢复为顶部导航条）。

> 📋 投递列表与🗑️ 回收站采用**网格卡片布局**：宽屏一行 3 张卡片、中屏 2 张、窄屏 1 张，尽量用满屏幕宽度，一屏能看更多记录。

## 一、投递列表（核心）

### 1.1 筛选与排序

| 控件 | 说明 |
| --- | --- |
| 🔍 搜索框 | 按**公司名或职位名**模糊搜索，输入即时过滤 |
| 状态下拉 | 已投递 / 简历被查看 / 初筛通过 / 面试中 / 二面 / 终面 / Offer / 已拒绝 / 已入职 |
| 渠道下拉 | 按招聘渠道过滤（含你自定义的渠道） |
| 测评下拉 | 全部 / 未测评 / 已测评 |
| 标签筛选 | 按标签关键词过滤 |
| 日期区间 | 按**投递日期**筛选（起 ~ 止） |
| 排序方式 | 按投递日期 / 公司名称 / 状态；点「↓ 降序 / ↑ 升序」切换方向 |
| 重置 | 一键清空所有筛选条件 |

**快捷筛选**（点一下应用，Capsule 高亮；**再点同一个即取消**）：

| 胶囊 | 筛出什么 |
| --- | --- |
| 今日添加 | 按**录入时间**筛选出今天新添加的记录（老数据无录入时间时按投递日期判断） |
| 本周投递 | 本周一至今投递的记录（按**投递日期**） |
| 待跟进 | 设置了「下次跟进日期」的记录 |
| 已投未面试 | 还没有面试时间、且状态未进入面试 / Offer / 结束的记录 |
| 超7天无进展 | 投递超过 7 天仍未推进的记录 |
| 待测评 | 已收到测评链接但还没完成 |
| 待笔试 | 笔试状态为「✍️ 未笔试」的记录（含还没收到链接的） |

> ⚠️ 注意口径区别：「今日添加」看的是**你什么时候录入的**，「本周投递」看的是**你什么时候投的**。手动改动上面任何一个筛选控件，快捷筛选会自动取消。

### 1.2 工具栏与批量管理

- **⬇ 导出 CSV**：把全部记录导出成 CSV（UTF-8 BOM，Excel 打开不乱码；不受当前筛选影响）。
- **☑ 批量管理**：进入批量模式，每条卡片前出现复选框。
  - 全选当前结果、批量改状态、**批量删除**（二次确认）、退出批量。
- **＋ 添加记录**：打开录入表单。
- 列表顶部还有一条**待测评提醒条**（有未完成测评时出现），可直接「查看」「全部标记已测评」。

### 1.3 排序规则

默认按投递日期倒序；**星标记录永远置顶**；日期相同时按最后更新时间倒序。

## 二、记录卡片：哪里可以点

卡片采用**固定两行结构**，保证网格布局下每张卡片整齐对齐：

- **第一行**：复选框（批量模式）+ 公司头像 + **公司名**（超长自动省略号，**悬停可看完整名称**）+ 右侧操作按钮；
- **第二行（徽章行）**：投递状态徽章 + 笔试徽章 + 职位名（超长同样省略）。

卡片上几乎所有元素都是可点的，不用每次都进编辑弹窗：

| 位置 | 元素 | 点一下会发生什么 |
| --- | --- | --- |
| 卡片左侧 | 复选框（批量模式下） | 选中 / 取消选中该条 |
| 第一行 | 公司名 | 打开**详情弹窗**（只读总览视图） |
| 第二行 | 状态徽章（如「已投递」） | 弹出状态选择器，直接改状态 |
| 第二行 | 笔试徽章 | 见下方说明 👇 |
| 第一行右侧 | ☆ / ★ | 星标 / 取消星标（星标记录置顶 + 卡片高亮） |
| 第一行右侧 | 复制 | 复制一条同内容的新记录（改日期/状态即可复用） |
| 第一行右侧 | 编辑 | 打开编辑表单 |
| 第一行右侧 | 删除 | 二次确认后移入**回收站**（不是永久删除） |
| 卡片下方 | 🔗 职位链接 | 新标签打开职位页 |
| 卡片下方 | 🔗 面试链接 | 仅「AI面试 / 一轮面试 / 二轮面试」状态显示，一键进入腾讯会议 / 飞书 / Zoom 等线上会议室 |
| 卡片下方 | 📝 测评链接 | 新标签打开测评页；状态为「已测评」后自动隐藏，只保留 ✅ 测评完成 徽章 |
| 卡片下方 | ✍️ 笔试链接 | 新标签打开笔试页；状态为「已笔试 / 无笔试」后自动隐藏，只保留笔试状态徽章 |
| 卡片下方 | 📝 待测评 / ✅ 测评完成 / 📨 待收测评 徽章 | 一键切换测评状态；「待收测评」点击会打开表单让你补填链接 |
| 卡片下方 | ⏳ 网申截止 / 测评截止 / 笔试截止 | 仅展示，倒计时颜色区分：临近 3 天黄 / 过期红（「无笔试」状态不显示笔试截止） |
| 卡片下方 | ⏰ 跟进日期 | 仅展示，颜色区分：过期红 / 今天橙 / 3 天内黄 / 其余绿 |

**笔试徽章的点击行为**（四态：点击任意笔试徽章都会弹出「更新笔试状态」弹窗，四选一直接改）：

| 徽章 | 含义 |
| --- | --- |
| ❓ 待确认 | 还不清楚这家要不要笔试（默认态，不触发提醒） |
| ✍️ 未笔试 | 确认有笔试、还没考（会进入笔试提醒） |
| ✅ 已笔试 | 笔试已完成 |
| ➖ 无笔试 | 这家只有综合测评、无笔试（不显示提醒） |

卡片下方还会显示：投递日期、工作地点、薪资、渠道、简历版本、联系记录条数、面试时间、网申截止（带倒计时颜色）、标签、跟进日期等元信息，一眼看全。

## 三、添加 / 编辑记录（表单字段）

点「＋ 添加记录」或卡片「编辑」打开，带红色 `*` 的是必填项。

| 字段 | 说明 |
| --- | --- |
| 公司名称 \* | 必填 |
| 职位名称 \* | 必填 |
| 工作地点 | 如「武汉」，用于统计看板的城市分布 |
| 薪资范围 | 如「20-35K·15薪」，用于薪资区间统计 |
| 招聘渠道 | 内置 20 种（BOSS直聘、智联、猎聘、牛客、内推、公司官网…）；点「＋ 自定义」可永久新增渠道 |
| 投递日期 \* | 必填，默认今天 |
| 当前状态 | 9 种状态之一 |
| 下次跟进日期 | 填了才会出现在「⏰ 跟进提醒」页 |
| 跟进原因 | 10 个常用选项 chips（等待笔试结果 / 等待面试通知 / 等待HR回复 / 等待Offer / 追问投递进度 / 确认面试安排 / 礼貌性跟进 / 补充材料 / 催推进度 / 电话未接通需再约），**点 chip 直接填入，也可手动输入自定义** |
| 网申截止日期 | 临近 3 天 / 过期会提醒 |
| 职位链接 | 卡片上可一键打开 |
| 面试时间 | 当「当前状态」切换为 AI面试 / 一轮面试 / 二轮面试时，字段自动显示为「面试安排」，可编辑；其余状态自动隐藏 |
| 面试链接 | 仅面试状态下显示，用于保存腾讯会议 / 飞书 / Zoom 等线上会议链接；非面试状态隐藏但数据保留 |
| 简历版本 | 下拉候选来自「简历版本库」，也可直接输入新名称 |
| 综合测评状态 | 未测评 / 已测评 |
| 测评链接 | 企业发来的测评系统链接 |
| 测评截止时间 | 填了会在卡片底部显示「⏳ 测评截止」倒计时徽章，临近 3 天 / 过期变色 |
| 笔试状态 | 四态：笔试待确认 / 无笔试 / 未笔试 / 已笔试（点卡片上的笔试徽章也能直接改） |
| 笔试链接 | 与测评链接**完全独立** |
| 笔试截止时间 | 填了会在卡片底部显示「⏳ 笔试截止」倒计时徽章（「无笔试」状态不显示） |
| 标签 | 逗号分隔，如「结构工程师, 大厂, 武汉」 |
| 简历附件 | PDF / DOC / DOCX；≤2MB 会保存文件内容可再下载，>2MB 仅记录文件名 |
| 备注 | JD 要点、内推人、注意事项等 |
| 📞 联系记录 | 表单内可添加多条沟通记录（时间 + 类型：电话/邮件/微信/面试/其他 + 内容） |

底部「取消 / 保存」。编辑弹窗比较特殊：**点遮罩或按 Esc 不会关闭**（防止误触丢失修改），只能点 ✕ / 取消 / 保存。

## 四、投递详情弹窗

点卡片标题打开，是一屏看完一条投递的只读视图：

- **顶部**：公司首字母头像（按公司名生成稳定配色）、状态徽章（**可点击直接改状态**）、公司名、职位、标签；
- **信息网格**：渠道、投递日期、工作地点、薪资、简历版本、面试时间、网申截止（带倒计时）、下次跟进日期、跟进原因等；
- **相关链接**：职位 / 面试 / 测评 / 笔试按钮直达；面试链接仅在面试状态显示；测评链接在「已测评」后隐藏；笔试链接在「已笔试 / 无笔试」后隐藏；
- **综合测评**：状态徽章（未测评 / 待测评 / 测评完成）+ 说明文案 + 「切换测评」按钮；
- **笔试**：状态徽章 + 说明文案 + 「切换笔试」按钮；
- **联系记录**：历次沟通时间、类型、内容；
- **备注**；
- **底部操作**：删除（入回收站）/ 复制 / 编辑。

## 五、综合测评与笔试（双轨管理）

很多公司既有**综合测评**（性格 / 行测）又有**专业笔试**，两者进度不同，因此本工具把它们**完全分开**记录。笔试状态是**四态**模型，与「是否需要笔试」的感受一致：

| 维度 | 综合测评 | 笔试 |
| --- | --- | --- |
| 链接字段 | 测评链接 | 笔试链接（独立） |
| 状态 | 未测评 / 已测评 | **❓ 待确认 · ➖ 无笔试 · ✍️ 未笔试 · ✅ 已笔试**（四态） |
| 卡片徽章 | 📨 待收测评 · 📝 待测评 · ✅ 已测评 | 四态徽章显示在卡片第二行（状态徽章旁），**点一下弹窗四选一** |
| 提醒 | 已收链接未完成会提醒 | 只有「✍️ 未笔试」的公司会收到笔试提醒（「无笔试」的公司完全不打扰） |
| 快捷筛选 | 待测评 | 待笔试 |

### 笔试四态怎么用

- **❓ 待确认**（默认）：还不清楚要不要笔试。显示灰色「待确认」徽章提醒你去确认，不产生笔试提醒；
- **➖ 无笔试**：这家只做综合测评。不显示橙色提醒，也不会有笔试提醒，列表清爽；
- **✍️ 未笔试**：确认有笔试且还没考。进入笔试提醒（已收链接提示「待完成」，未收链接提示「留意邮箱」）；
- **✅ 已笔试**：完成笔试，绿色徽章。

> 状态可在三处修改：编辑表单的「笔试状态」下拉、卡片/跟进列表上的笔试徽章点击弹窗、详情页的切换按钮。旧数据的「是否需要笔试」字段会被自动换算成新四态，兼容老备份。

## 六、跟进提醒

列出所有设置了「下次跟进日期」的记录，按日期从近到远排序。

**每条卡片包含**

- 公司 + 职位 + 投递状态徽章 + **笔试徽章（点击弹窗直接改状态）**；
- 跟进日期与倒计时文案：已过期 N 天（红）/ 今天（橙）/ N 天后（绿）；
- 📌 跟进原因（如填了）；
- 四个链接直达：🔗 职位链接 / 📝 测评链接 / ✍️ 笔试链接（及面试链接），缺失时显示淡色「暂无…链接」提示；已完成的测评 / 笔试不再显示对应链接；
- 操作：**完成跟进**（可同时补一条联系记录，并顺便安排下次跟进日期 + 原因）与 **编辑**。

**顶部工具**

| 按钮 | 作用 |
| --- | --- |
| 🔔 提醒汇总 | 弹窗一屏看全四类待办 |
| ⚡ 立即提醒 | 立刻在右上角弹出当前待办卡片 |
| 全部标记已跟进 | 一键清空所有跟进日期 |

## 十四、页面内提醒系统

**不需要任何浏览器通知权限，也不需要后台服务**——提醒完全发生在页面内，以右上角浮动卡片呈现（带图标、分类色、进度条，可手动关闭，约 9 秒自动消失）。

- 打开页面时若有待办，**自动弹一次**（每次会话只弹一次，不打扰）；
- 点「⚡ 立即提醒」可随时手动触发；
- 点「🔔 提醒汇总」可在一屏看全所有待办；
- 「⏰ 跟进提醒」标签上的数字角标 = 待处理提醒条数。

**四类提醒**

| 分类 | 触发条件 |
| --- | --- |
| 📌 求职跟进 | 下次跟进日期已到期或已过期 |
| ⏰ 网申截止 | 截止日期 ≤3 天或已过期 |
| 📝 综合测评 | 已收到测评链接但未完成（未收到链接的只提示留意邮箱） |
| ✍️ 笔试提醒 | 仅对笔试状态为「✍️ 未笔试」的公司：已收链接 → 待完成笔试；未收链接 → 留意邮箱待收（「无笔试」「待确认」的公司不打扰） |

回收站里的记录不参与提醒。

> 想快速验证：随便加一条记录，「下次跟进日期」填今天、「网申截止」填明天，保存后到「⏰ 跟进提醒」页点 **⚡ 立即提醒** 即可看到卡片。

## 十五、数据存储与安全

- 数据保存在**当前浏览器**的 `localStorage`，仅在这台设备上，不上传任何服务器；
- 换设备 / 换浏览器**不会自动同步**，请用「💾 数据管理」定期导出 JSON；
- 清除浏览器数据、隐私模式关闭后会丢失记录，**重要数据务必备份**；
- 简历附件以文件方式存入本地存储，请注意 5MB 容量预警。

## ❓ 常见问题

**Q：打开页面一片黑？**
A：可能处于深色模式，点右上角 ☀️ 切回浅色（会被记住）。

**Q：数据怎么迁移到新电脑？**
A：旧电脑「💾 数据管理 → 导出 JSON」，新电脑打开页面后「导入 JSON」。

**Q：网站导航里某个站点显示空白？**
A：该站点禁止被 iframe 内嵌，属正常现象。需要的话用你自己的本地代理并在「⚙️ 代理设置」中填写模板。

**Q：导入 Excel 提示格式不对？**
A：先点「⬇ 下载导入模板」，按模板列名整理；必填只有「公司名称 + 职位名称」。

**Q：笔试徽章的「❓ 待确认」和「➖ 无笔试」有什么区别？**
A：「待确认」是默认态，表示还不清楚这家要不要笔试；「无笔试」表示确认这家只有综合测评。两者都**不会触发笔试提醒**，想改状态点徽章弹窗四选一即可。

**Q：删除的记录还能找回吗？**
A：能，去「🗑️ 回收站」恢复。

**Q：切换到「AI 面试 / 一轮面试」后，面试时间/截止时间框不能编辑？**
A：该字段会根据当前状态自动启用/禁用。如果遇到无法输入，请先确认状态已切到面试类状态；若仍无法点击，尝试刷新页面后重试。所有 datetime-local 时间框均保持最小宽度，避免在窄屏下被浏览器隐藏日期选择图标。
