# 求职投递管理 (Job Tracker)

一个**纯前端、零依赖、单文件**的求职投递管理工具。所有数据保存在浏览器本地（`localStorage`），无需服务器、无需注册、无需联网即可使用。

> 适合正在找工作的同学集中管理投递记录、跟进状态与面试安排，不再用 Excel 手动维护。

---

## ✨ 功能特性

- 📋 **投递列表**：添加 / 编辑 / 删除记录，支持搜索、按状态 / 渠道 / 测评 / 标签 / 日期区间筛选与排序，并提供批量管理；另有**快捷筛选预设**（本周投递 / 待跟进 / 已投未面试 / 超 7 天无进展 / 待测评）一键过滤。
- 📊 **统计看板**：投递趋势、状态分布等数据可视化，快速了解求职进度。
- 📄 **简历版本库**：管理针对不同岗位打磨的多份简历版本。
- ⏰ **跟进提醒**：记录面试、后续动作等跟进事项，支持系统级桌面通知。
- 🗓️ **面试日历**：按日期直观查看面试安排。
- 💾 **数据管理**：CSV 导入 / 导出、本地备份与恢复，方便换设备或长期保存。
- 🌐 **网站导航**：内置常用招聘网站导航，可自定义，并支持可选的本地代理用于跨域内嵌浏览。
- 📝 **综合测评提醒**：投递后默认「未测评」，可一键切换为「已测评」并填写测评链接，支持按测评状态筛选与系统通知，再也不漏掉企业的测评。
- 🌙 **深色 / 浅色主题**：一键切换，自动记忆偏好。

## 🚀 快速开始

1. 克隆或下载本仓库；
2. 直接用浏览器（推荐 Chrome / Edge）打开 `job-tracker.html` 即可使用；
3. 首次使用建议前往「💾 数据管理」页导出一份 CSV 作为备份。

无需安装任何依赖、无需构建步骤、无需联网（「网站导航」页的内嵌浏览需要联网）。

> ℹ️ 双击打开属于 `file://` 方式，浏览器（Chrome / Edge）会禁用**系统级**通知——但页面内的提醒卡片照常工作，不影响使用。若确实想要操作系统层面的通知，见下方「🖥️ 可选」一节。

## 💾 数据存储与备份

- 数据保存在当前浏览器的 `localStorage`，**仅存在于你正在使用的这台浏览器**，不上传任何服务器。
- 换设备 / 换浏览器**不会自动同步**，请使用「💾 数据管理 → 导出 CSV / 备份」定期保存。
- 清空浏览器缓存或数据会丢失记录，重要数据请务必及时备份。

## 🔔 提醒（默认走页面提示，零配置）

**最简单：什么都不用装。** 直接用浏览器打开 `job-tracker.html`，提醒会以**页面右上角的浮动卡片**弹出（滑入动画、带进度条、可手动关闭、自动消失）：

- 打开页面时，若有待办会自动弹一次（每次会话只弹一次，不打断操作）；
- 点「⏰ 跟进提醒」页的 **⚡ 立即提醒** 可随时手动触发；
- 点右上角的 **🔔** 按钮，可在一屏里看全当前三类待办（本地文件模式下它叫「提醒汇总」）；
- 「⏰ 跟进提醒」标签上的**数字角标** = 待处理提醒条数（跟进到期 + 网申临近/过期 + 有链接的待测评）。

三类提醒：求职跟进（到期 / 过期）、网申截止（≤3 天 / 已过期）、综合测评（已收到链接待完成 / 未收到链接提醒留意邮箱）。回收站里的记录不参与提醒。

> 想验证效果：随便加一条记录，把「下次跟进日期」填成今天，「网申截止日期」填成明天，保存后回到「⏰ 跟进提醒」页点 **⚡ 立即提醒** 即可看到卡片。

## 🖥️ 可选：真正的系统级桌面通知

**这一节可以完全跳过**——上面的页面提示已经是默认行为，不需要任何设置。只有当你确实想要**操作系统层面的通知弹窗**（能出现在 Windows 通知中心）时才需要看下面。

原因：浏览器禁止 `file://` 页面发系统通知，必须先让页面跑在 `http://` 协议下。

**一句话做法**：双击项目目录里的 **`启动-系统通知版.bat`**（需已安装 Python 3，脚本会自动在 PATH 与常见安装目录里查找 `python.exe`）。它会：

1. 在本机 8765 端口启动一个只监听 `127.0.0.1` 的静态服务（端口被占用会自动往后找）；
2. **自动**用浏览器打开 `http://127.0.0.1:8765/job-tracker.html`——这一串就是「用 http://localhost 打开」的意思，`localhost` 就是本机，你不用自己拼地址；
3. 在页面点 **🔔** 并允许通知权限，之后即可收到系统通知。

关闭那个黑窗口（或 Ctrl+C）即停止服务，数据全部保存在浏览器本地，不受影响。

**其他等价方式**：VS Code 的 Live Server、`npx serve`、`python -m http.server` 等，只要能以 `http://localhost` 打开本页即可。
