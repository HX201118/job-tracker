# 求职投递管理 (Job Tracker)

一个**纯前端、零依赖、单文件**的求职投递管理工具。所有数据保存在浏览器本地（`localStorage`），无需服务器、无需注册、无需联网即可使用。

> 适合正在找工作的同学集中管理投递记录、跟进状态与面试安排，不再用 Excel 手动维护。

---

## ✨ 功能特性

- 📋 **投递列表**：添加 / 编辑 / 删除记录，支持搜索、按状态 / 渠道 / 测评 / 标签 / 日期区间筛选与排序，并提供批量管理；另有**快捷筛选预设**（本周投递 / 待跟进 / 已投未面试 / 超 7 天无进展 / 待测评 / 待笔试）一键过滤，**再点一次同一个即可取消**。
- 📊 **统计看板**：投递趋势、状态分布等数据可视化，快速了解求职进度。
- 📄 **简历版本库**：管理针对不同岗位打磨的多份简历版本。
- ⏰ **跟进提醒**：记录面试、后续动作等跟进事项，到期自动在页面内弹出提醒；每条待办下方直接展示「🔗 职位链接」「📝 测评链接」「✍️ 笔试链接」，链接缺失时给出「暂无」提示；填写「下次跟进日期」时可一并填写**跟进原因**（提供常用选项也可自定义），方便回顾为何跟进。
- 🗓️ **面试日历**：按日期直观查看面试安排。
- 💾 **数据管理**：CSV 导入 / 导出、本地备份与恢复，方便换设备或长期保存。
- 🌐 **网站导航**：内置常用招聘网站导航，可自定义，并支持可选的本地代理用于跨域内嵌浏览。
- 📝 **综合测评提醒**：投递后默认「未测评」，可一键切换为「已测评」并填写测评链接，支持按测评状态筛选与页面内提醒，再也不漏掉企业的测评。
- ✍️ **笔试管理（与测评独立）**：单独的「笔试链接」与笔试状态（未笔试 / 已笔试），与综合测评分开记录，详情页可一键切换笔试状态，互不混淆；并可标记每条投递**是否需要笔试**（需要笔试 / 仅测评无需笔试 / 待确认），**只有标记为「需要笔试」的公司才会收到笔试提醒**，避免对仅测评级的公司造成打扰。
- 🌙 **深色 / 浅色主题**：一键切换，自动记忆偏好。
- ⬆️ **返回顶部**：在「📋 投递列表」「⏰ 跟进提醒」两页向下滚动后，右下角自动出现「↑ 返回顶部」浮动按钮，一键回到顶部，长列表浏览更顺手。

## 🚀 快速开始

1. 克隆或下载本仓库；
2. 直接用浏览器（推荐 Chrome / Edge）打开 `job-tracker.html` 即可使用；
3. 首次使用建议前往「💾 数据管理」页导出一份 CSV 作为备份。

无需安装任何依赖、无需构建步骤、无需联网（「网站导航」页的内嵌浏览需要联网）。

> ℹ️ 提醒全部在**页面内**完成（右上角浮动卡片 + 提醒汇总弹窗），不需要任何浏览器通知权限，也不需要额外的启动脚本。

## 💾 数据存储与备份

- 数据保存在当前浏览器的 `localStorage`，**仅存在于你正在使用的这台浏览器**，不上传任何服务器。
- 换设备 / 换浏览器**不会自动同步**，请使用「💾 数据管理 → 导出 CSV / 备份」定期保存。
- 清空浏览器缓存或数据会丢失记录，重要数据请务必及时备份。

## 🔔 提醒（纯页面内，零配置）

**什么都不用装。** 直接用浏览器打开 `job-tracker.html`，提醒会以**页面右上角的浮动卡片**弹出（滑入动画、带进度条、可手动关闭、自动消失）：

- 打开页面时，若有待办会自动弹一次（每次会话只弹一次，不打断操作）；
- 点「⏰ 跟进提醒」页的 **⚡ 立即提醒** 可随时手动触发；
- 点 **🔔 提醒汇总** 按钮，可在一屏里看全当前四类待办；
- 「⏰ 跟进提醒」标签上的**数字角标** = 待处理提醒条数（跟进到期 + 网申临近/过期 + 有链接的待测评 + 需笔试待完成）。

四类提醒：求职跟进（到期 / 过期）、网申截止（≤3 天 / 已过期）、综合测评（已收到链接待完成 / 未收到链接提醒留意邮箱）、笔试（需笔试且未完成：已收到链接的待完成 / 未收到链接的待收链接——**仅对标记为「需要笔试」的公司提醒，明确「无需笔试」的公司不打扰**）。回收站里的记录不参与提醒。

提醒**不依赖浏览器通知权限**，也不需要本地服务器——它完全发生在页面内，关掉网页就自然结束。

> 想验证效果：随便加一条记录，把「下次跟进日期」填成今天，「网申截止日期」填成明天，保存后回到「⏰ 跟进提醒」页点 **⚡ 立即提醒** 即可看到卡片。
